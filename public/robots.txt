# robots.txt — https://www.skediodesign.in
#
# Policy: open by default. This is a public marketing site, so everything is
# crawlable except the two genuinely non-public path groups at the bottom.
# Assets are never blocked — hashed JS/CSS live under /assets/ and every file
# in public/ is served from the site root, and neither matches any Disallow.
#
# ---------------------------------------------------------------------------
# WHY THERE IS EXACTLY ONE User-agent GROUP
# ---------------------------------------------------------------------------
# A crawler reads ONLY the single group whose User-agent token matches it most
# specifically. Groups do NOT inherit from, merge with, or fall back to
# `User-agent: *`. Two consequences, both of which have bitten this file before:
#
#   1. A `User-agent: GPTBot` group silently takes precedence over
#      `User-agent: *` for GPTBot, and every rule omitted from it is omitted
#      entirely. A dedicated group that lists only `Allow: /` therefore LOSES
#      the `Disallow: /api/` below — AI crawlers would reach the authenticated
#      API route that search crawlers cannot.
#   2. The classic footgun is someone trying to "block AI crawlers" by editing
#      the `*` group to `Disallow: /`. Because Googlebot matches `*`, that
#      deindexes the entire site. Search crawlers and AI crawlers are only kept
#      independent here by never sharing a group.
#
# One `*` group means one source of truth: no bot, human or AI, can be affected
# by another bot's rules.
#
# AI crawlers (GPTBot, ChatGPT-User, ClaudeBot, PerplexityBot, Google-Extended,
# Applebot-Extended, CCBot, Bytespider) are deliberately NOT blocked — being
# cited by AI answer engines is a goal for this studio, and /llms.txt exists to
# serve them. If that policy ever changes, ADD a new group for the specific bot
# and leave the `*` group below untouched, so search crawlers are unaffected:
#
#     User-agent: GPTBot
#     Disallow: /
#
# ---------------------------------------------------------------------------

User-agent: *

# Authenticated internal API. /api/cron/digest is the only route here; it
# requires `Authorization: Bearer $CRON_SECRET` and returns 401 without it, and
# it has no indexable content. Blocking it only keeps it out of results and off
# the crawl budget — this is hygiene, NOT security. The route is protected by
# the bearer-secret check in src/server.ts, which robots.txt has no role in.
